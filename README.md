# Data_analysis_of_Heart_disease_dataset
Data analysis of heart disease datasets from different domains through help of various tools like numpy,panda,seaborn,matploib on google colab.
Input Features: 13 physiological metrics, including Age, Sex, Chest Pain Type (cp), Resting Blood Pressure (trestbps), Serum Cholesterol (chol), Fasting Blood Sugar (fbs), and Maximum Heart Rate Achieved (thalach).

Target Variable: target (0 = No Heart Disease, 1 = Heart Disease Present).

Project Objective: To perform exploratory data analysis (EDA) and train machine learning classification models (like Random Forest and Logistic Regression) that identify high-risk patients based on their clinical baselines.
